StORM
=====

StORM computes stellar oscillation frequencies for a given stellar model describing the internal structure of the star. The main purpose of these computations is to derive stellar properties from observed oscillation frequencies, i.e. the field of asteroseismology. StORM's main distinguishing feature is the inclusion of rotational deformation starting from only a one-dimensional stellar model. For some inspiration of what StORM is capable of, a list of papers using StORM can be found `here <https://www.scixplorer.org/public-libraries/y6tp8AkfROi8qP4Dxfdpkw>`_. Since StORM can read in any stellar model, there are no explicit constraints on the type of star one can model with StORM.
