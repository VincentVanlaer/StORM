Thank you for your interest in contributing to StORM! There are no strict requirements for contributing at the moment except for the LLM policy below.

If you want to report an issue or have a request/question, please open an issue or start a discussion. Given the smaller size of this project, there are no strict code style guidelines, but do make sure that `cargo fmt` and `cargo test` pass.

# LLM policy

This project is LLM-free. The use of LLMs or other GenAI tools when contributing to this project are therefore prohibited. If you are unsure/struggling to contribute without LLMs, feel free to contact me and I'm happy to assist.
